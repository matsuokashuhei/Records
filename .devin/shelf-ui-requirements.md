# レコード棚UI 要件チェックリスト

参照画像: レコード店の中央棚(木製格子棚にLPジャケットを1枚ずつ立てかけた
ディスプレイ)。木の質感は**コード描画のグラデーション+陰影**で表現する
(画像素材は使わない)。

レビュアーはこのリスト全項目を採点すること。

## 1. 木製シェルフの構造(枠組み)

- [ ] 1-1. 外周フレーム: 現在の四辺8pt余白を、厚みのある木の外枠に置き換える
      (上・下・左・右それぞれ板厚分)
- [ ] 1-2. 縦仕切り板: 列間の隙間(現行 `columnSpacing: 12`)を木の縦板にする。
      区画同士が板で隔てられた構造に見えること
- [ ] 1-3. 横棚板: 行間の隙間(現行 `rowSpacing: 14`)を木の棚板にする。
      ジャケットがこの板の上に「載っている」見え方であること
- [ ] 1-4. 木の質感: 暖色ミディアムブラウン基調。板の上面は光を受けて明るく、
      下面は暗い(上下で明暗のあるエッジ表現)。グラデーション/陰影による
      コード描画であること(画像アセット不使用)
- [ ] 1-5. 棚板の落ち影: 各棚板が一段下の区画内部に影を落とす
      (区画の上端が少し暗い)

## 2. 区画(キュービー)内部

- [ ] 2-1. 背板: 各区画の背面は暗い板(ほぼ黒〜暖みのある焦茶)。
      ジャケットの周囲に背板が見えること
- [ ] 2-2. 内側の陰影: 区画の左右・上の内壁に内シャドウを入れて奥行きを出す
- [ ] 2-3. 区画>ジャケット: ジャケットの上下左右に背板が見える内側余白
      (目安: ジャケットは区画の75〜85%程度)

## 3. ジャケットの見せ方

- [ ] 3-1. 底辺揃えの立てかけ: ジャケットは棚板の上に底辺を付けて配置
- [ ] 3-2. 奥行き感: 後ろに倒れている表現。`rotation3DEffect`(x軸数度)または
      上辺をわずかに狭める擬似パース等で実現
- [ ] 3-3. 個別の微差: レコードごとに1〜2°程度の左右傾き・わずかな
      手前/奥のズレ。entry.id等から決定論的に算出し、表示ごとに変わらないこと
- [ ] 3-4. 接地影・背面への投影: ジャケット下端に棚板への接触影、
      背板に柔らかい投影
- [ ] 3-5. (任意) スリーブ光沢: 斜めの淡いハイライトを重ねて透明袋の
      光沢感を出す

## 4. 照明・雰囲気

- [ ] 4-1. 光源は上: すべての影・エッジ明暗を上方向の光で統一
- [ ] 4-2. 全体のトーン: ウィンドウ背景を暗くし、暖色系の環境光で棚を
      浮かせる
- [ ] 4-3. (任意) ヴィネット: 四隅をわずかに暗くする

## 5. 空き区画

- [ ] 5-1. 空きスロットは「空の区画」(背板+内影のみ)として描画する
- [ ] 5-2. ドロップ先として認識できるよう、isTargeted時は区画内が
      ハイライトされる

## 6. 既存機能との整合

- [ ] 6-1. 座標系の維持: `slotInsertion`/`slotRect`/`slotScreenCenter`/
      `overlayGridPoint` 等のセル矩形モデルを維持し、区画=新セルサイズ
      (ジャケット+内側余白)、間隔=板厚の差し替えで計算式が成り立つこと。
      スロット判定・ドラッグ&ドロップ・右クリックメニューが従来通り動作する
- [ ] 6-2. ヒット領域: クリック(再生)/右クリック(削除メニュー)/ドロップの
      対象領域は区画全体
- [ ] 6-3. ドラッグゴースト: GhostPanelはジャケット画像のみを運ぶ
      (区画は持ち運ばない)。従来の挙動を壊さない
- [ ] 6-4. ホバー再生ボタン: ジャケット上に重ねる。区画内のジャケット位置に
      合わせて配置・サイズを調整
- [ ] 6-5. ドロップターゲット表示: `dropTargetOpacity`の半透明セルに代わり、
      区画内(背板の発光や隙間インジケータ等)でドロップ位置を示す
- [ ] 6-6. ツールバー・信号ボタン: 左上/右上のガラスカプセルが外枠の上に
      重なっても破綻しない配置(必要ならオフセット調整)
- [ ] 6-7. ウィンドウサイズ: `.windowResizability(.contentSize)`の理想サイズ
      計算を「区画数×区画サイズ+板厚+外枠」に更新。ウィンドウと棚の
      高さが一致すること

## 7. パラメータ化すべき寸法

- [ ] 7-1. 区画の内側余白(ジャケット/区画比率)が1箇所の定数で調整可能
- [ ] 7-2. 板厚(縦仕切り・横棚板・外枠)が定数で調整可能
- [ ] 7-3. 木の色・明度、背板の色が定数で調整可能
- [ ] 7-4. ジャケットの傾き・微差の量が定数で調整可能

## プロジェクト鉄則(全実装で必須)

- [ ] A. 新規UI要素・状態遷移に`os.Logger`を仕込む
      (subsystem: `com.cacheandbuffer.Records`、補間は `\(v, privacy: .public)`)
- [ ] B. ファイル追加・削除後は
      `DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer xcodegen generate`
      を実行。project.pbxprojの手編集禁止
- [ ] C. `RecordsApp.init`内の `--catalog-test <URL> [--play]` CLI経路を壊さない
- [ ] D. `Shared/`配下の変更はウィジェットにも影響することを意識する
- [ ] E. ドラッグ中の高頻度なSwiftUI状態更新禁止(AGENTS.mdのEXC_BAD_ACCESS
      事例)。ゴースト追従は命令的にパネルを動かす既存方式を維持
- [ ] F. デバッグビルドが通ること:
      `xcodebuild -project Records.xcodeproj -scheme Records -configuration Debug -derivedDataPath .build build`
