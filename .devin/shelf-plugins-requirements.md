# シェルフエフェクトプラグイン機構 要件チェックリスト

前提: feature/cubby-shelf-ui(PR #21)はリファレンス実装として保存済み。
本タスクは **main から作り直し**。まずプラグイン基盤のPRを作り、
3つのプラグインはそのブランチから派生させて個別PRにする。

レビュアーは該当PRの節の項目を採点すること。

## P0. プラグイン基盤(PR1: feature/shelf-plugin-framework → main)

- [ ] P0-1. プラグイン定義: 各エフェクトを「プラグイン」として登録できる
      プロトコル/型。id(安定な文字列)・表示名・有効フラグ・調整可能な
      パラメータ群を持つ
- [ ] P0-2. パラメータモデル: スライダー等で調整可能な型付きパラメータ
      (範囲・デフォルト値を含む)。今後 enum 選択等の型追加を見込める拡張性
- [ ] P0-3. 永続化: プラグインの有効/無効とパラメータ値をシェルフ単位で
      settings.json に保存。既存settings.json(キー無し)からの
      デコード互換を保つ(Codableの後方互換。新キーは省略時デフォルト)
- [ ] P0-4. レジストリ: 利用可能なプラグイン一覧を1箇所で登録・列挙できる。
      適用順はレジストリ順で決定論的
- [ ] P0-5. 適用ポイント: レコードセルのジャケット描画に対し、有効な
      プラグインが合成される仕組み。少なくとも以下のフックを持つ:
      (a) ジャケット本体への修飾(変形・回転等)
      (b) ジャケットへのオーバーレイ重畳
      (c) セル単位の装飾(影・光等)
      プラグインは必要なフックだけ実装すればよい
- [ ] P0-6. 設定画面: SettingsViewにプラグインセクションを追加。
      各プラグイン=選択(トグル)可能・有効時にパラメータ調整UI(スライダー等)
      を表示。変更はフォーカス中シェルフへ即時反映(既存のShelfPickersと
      同じ@ObservedObjectパターン)
- [ ] P0-7. 登録ゼロでも破綻しない: プラグイン未登録の状態で基盤だけが
      存在してもよい(セクション非表示等)。ビルド・既存動作に影響なし
- [ ] P0-8. 将来の棚レベルプラグイン(木枠・区画・ヴィネット等)を見据え、
      ジャケット以外のフック追加が可能な構造(本PRで実装は不要、
      拡張可能な設計であること)

## P1. プラグイン「奥行き感(後傾)」(PR2: feature/plugin-lean-depth → framework)

- [ ] P1-1. ジャケットが背板に後ろへ倒れている表現。
      rotation3DEffect(x軸, anchor .bottom)または上辺を狭める擬似パースで実現
- [ ] P1-2. 調整可能パラメータ: 「立てかけ具合」0-50%(step 2.5)の
      単一スライダー。棚の奥行きの何%の位置までジャケット上辺が
      届くかを指定し、内部で角度=asin(lean%×sin15°)を逆算する
      (パースは0.7固定)。settings.jsonに永続化
- [ ] P1-3. 無効時は元の平面表示と完全に同じ見た目・レイアウト
- [ ] P1-4. タップ/ドラッグ等のヒット領域が壊れない(修飾後もセルの
      インタラクションが機能する)

## P2. プラグイン「スリーブ光沢」(PR3: feature/plugin-sleeve-gloss → framework)

- [ ] P2-1. 透明ビニール袋に入ったレコードのような、斜めの淡い
      ハイライト帯をジャケットに重ねる
- [ ] P2-2. 調整可能パラメータ: 光沢強度(不透明度)、帯の角度、帯の幅 等
- [ ] P2-3. 無効時はオーバーレイ完全非表示(残像・レイアウト影響なし)

## P3. プラグイン「上からの光源」(PR4: feature/plugin-top-light → framework)

- [ ] P3-1. ジャケット/セルの影・エッジ明暗を「上方向の光」で統一する
      表現(例: ジャケットの下向き投影、上辺の受光ハイライト、
      セル上部の柔らかい照光等)
- [ ] P3-2. 調整可能パラメータ: 影の強さ(不透明度・ぼかし等)、
      ハイライト強度 等
- [ ] P3-3. 既存のセル影(rounded rectの固定shadow)との関係を整理する
      (有効時はプラグイン側の光源表現に統一、無効時は従来通り)
